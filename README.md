# 간트 차트

Vite + Vanilla JS + [frappe-gantt](https://github.com/frappe/gantt)로 만든 개인용 간트차트입니다. 화면은 영어입니다. 백엔드 없이 브라우저에서만 동작하고, 데이터는 localStorage에 자동 저장됩니다.

**바로 쓰기**: https://ben6306.github.io/my-gantt/

## 앱으로 설치하기 (추천)

터미널 없이 아이콘을 눌러 여는 방법입니다. 한 번 열어 두면 인터넷이 없어도 실행됩니다.

- **Chrome**: https://ben6306.github.io/my-gantt/ 을 열고 주소창 오른쪽의 설치 아이콘(모니터에 ↓)을 누르거나, ⋮ 메뉴 → 전송, 저장, 공유 → 페이지를 앱으로 설치. 응용 프로그램 폴더·Launchpad에 "Gantt"가 생기고 Dock에 끌어다 둘 수 있습니다.
- **Safari** (macOS Sonoma 이상): 사이트를 열고 파일 → Dock에 추가.

데이터는 설치한 앱의 저장 공간에 따로 저장됩니다. 다른 곳(localhost, 다른 브라우저)에서 쓰던 태스크는 그쪽에서 **Export JSON** → 앱에서 **Import JSON**으로 옮기세요. Safari로 Dock에 추가한 앱은 Safari와도 저장 공간이 따로입니다.

새 버전을 배포하면 인터넷이 연결된 상태에서 앱을 열 때 자동으로 새 버전이 열립니다.

## 개발용 실행

```bash
npm install
npm run dev
```

터미널에 표시되는 주소(기본값 http://localhost:5173)를 브라우저에서 엽니다.

배포용 빌드는 `npm run build`이며 결과물은 `dist/`에 생깁니다. `npm run preview`로 빌드 결과를 미리 볼 수 있습니다.

## 기능

- 왼쪽 태스크 목록: 이름·시작일·종료일·진행률, 행마다 수정/복제/삭제 버튼, 클릭하면 목록과 차트에서 함께 강조
- 종류 세 가지(모달 맨 위에서 선택)
  - **Task**: 기간이 있는 일반 태스크
  - **Milestone**: 하루짜리 마름모. 날짜 하나와 Done 체크
  - **Group**: 태스크를 묶는 상위 태스크. 태스크 모달의 "In group"으로 넣는다. 기간·진행률(자식 기간 가중 평균)은 자식으로 자동 계산되고 막대를 끌 수 없다. 목록의 ▸/▾(또는 ←/→)로 접고 편다. 한 단계만 된다(그룹 안의 그룹 없음). 그룹을 지우면 자식은 그룹 밖으로 남는다
- 그룹이나 그룹 안 태스크를 선택한 채 "Add task"를 누르면 새 태스크가 그 그룹에 들어감
- 주말은 옅은 회색, 한국 공휴일(2025~2027, 대체공휴일 포함)은 옅은 빨강으로 표시하고 마우스를 올리면 이름. 모달·팝업에 근무일 수(주말·공휴일 제외). 월 보기에서는 음영을 숨김
- 늦은 태스크 강조: 종료일이 지났는데 100%가 아니면 빨강(막대 실선 테두리), 지난 기간 비율보다 진행률이 20%p 넘게 낮으면 주황(점선). 목록 종료일에 아이콘, 위에 "N late"
- 메모: 모달의 Notes. 목록 이름 옆 아이콘·툴팁, 막대 팝업에 표시
- 복제: 행의 복제 버튼 또는 행을 선택하고 ⌘D(Ctrl+D). 바로 아래에 "(copy)"로, 그룹은 자식까지
- 검색·필터: 열 제목 위 검색칸(이름·메모·소속 그룹 이름), Filter 메뉴(완료 숨기기·늦은 것만·색). 자식이 맞으면 그룹도 보임. 필터 중에는 순서 바꾸기가 꺼지고, PNG는 보이는 행만 그림. 필터는 저장하지 않음
- 기준선: More → Save current dates as baseline으로 지금 날짜를 저장해 두면, 날짜가 바뀐 만큼 막대 아래 회색 막대로 처음 계획이 보이고 팝업에 "finishes 3 days late"처럼 표시. Clear baseline으로 지움
- 오른쪽 간트 차트: 의존성 화살표, 드래그로 기간·진행률 변경, 일/주/월 보기
- 줌: −/+ 버튼으로 8단계(일 64·45·30·20px, 주 140·100px, 월 120·90px), "Fit"으로 전체 일정을 한 화면에
- "Export PNG": 스크롤과 상관없이 보이는 모든 행(접힌 그룹의 자식·필터에 걸린 행 제외)과 첫 태스크~마지막 태스크 기간을 지금 줌 그대로 한 장의 이미지로 저장
- 태스크 추가/수정 모달: 색상 10가지 선택, 종료일 ≥ 시작일, 진행률 0~100 정수 검증, 순환 의존 방지
- 헤더의 프로젝트 이름: 클릭해서 바로 바꿀 수 있고 자동 저장
- 프로젝트 여러 개: 헤더 이름 옆 ▾ 메뉴에서 전환·삭제, "New project"는 새 빈 프로젝트를 추가 (다른 프로젝트는 그대로)
- 헤더의 "Export JSON"·"Import JSON" 버튼: JSON 파일로 백업하고 복원 (아래 "백업과 복원" 참고)
- 헤더의 "More" 메뉴: 기준선, 공유 링크, CSV, 모든 프로젝트 백업, 파일 자동 저장
- 헤더 왼쪽의 백업 상태: 자동 저장 중이면 "Auto-saved 3:04 PM", 아니면 마지막 백업이 얼마나 지났는지(7일이 넘거나 한 번도 없으면 주황)
- 실행 취소/다시 실행: ⌘Z / ⇧⌘Z (윈도우 Ctrl+Z / Ctrl+Y), 목록 위 화살표 버튼. 이력은 페이지를 새로고침하면 사라짐
- 긴 태스크 이름: 목록에서 두 줄까지 보이고, 열 제목 "Task" 옆 ↔ 버튼(또는 목록·차트 경계선의 손잡이 더블클릭)으로 가장 긴 이름에 맞춰 목록을 넓힘. 경계선을 끌어 직접 조절, 포커스 후 ←/→. 폭은 기억됨
- 목록 순서 바꾸기: 행 왼쪽 손잡이를 끌어서 옮기거나, 행을 선택하고 Alt+↑/↓. 차트 순서도 같이 바뀜. 그룹은 자식과 함께, 그룹 안 태스크는 그 그룹 안에서만 움직임(그룹을 바꾸려면 모달의 "In group")
- 모든 변경은 즉시 localStorage(`my-gantt:projects`, `my-gantt:current-project`)에 저장. 프로젝트 전환 기능 이전에 쓰던 `my-gantt:tasks`·`my-gantt:project-name`은 처음 열 때 첫 프로젝트로 옮기고 지우지 않음

## 데이터 형식

```js
{ id: "2", name: "Requirements", start: "2026-12-04", end: "2026-12-10", progress: 20, dependencies: "1", color: "blue" }
```

`dependencies`는 선행 태스크 id를 쉼표로 이은 문자열입니다(예: `"1, 3"`, 없으면 `""`).

`color`는 `purple`, `blue`, `sky`, `teal`, `green`, `yellow`, `orange`, `red`, `pink`, `gray` 중 하나입니다. 없거나 모르는 값이면 순서대로 기본 색이 들어갑니다.

아래 필드는 선택 사항이라 없으면 일반 태스크입니다(예전 데이터·백업도 그대로 열림). 기본값이면 저장하지 않습니다.

| 필드 | 뜻 |
| --- | --- |
| `type` | `"milestone"`(하루짜리, `end` = `start`) 또는 `"group"` |
| `parent` | 속한 그룹의 id (그룹은 가질 수 없음) |
| `collapsed` | 그룹이 접혀 있으면 `true` |
| `notes` | 메모 |
| `baselineStart`, `baselineEnd` | 기준선 날짜 |

목록 배열에서 그룹의 자식은 항상 그룹 바로 뒤에 이어집니다. 그룹의 `start`·`end`·`progress`는 자식이 있으면 자식에서 계산한 값으로 저장됩니다. 그룹은 `dependencies`를 갖지 않고 다른 태스크의 선행이 될 수도 없습니다.

## 자동 백업 (Chrome·Edge)

More → Backup → **Auto-save to a file…**에서 JSON 파일을 한 번 고르면, 이후 바뀔 때마다 모든 프로젝트를 그 파일에 저장합니다. iCloud Drive 같은 폴더에 두면 이 Mac이 고장 나도 남습니다.

- 앱을 다시 열었을 때 브라우저가 다시 허락을 받으라고 하면 헤더에 "Auto-save paused"가 보입니다. 누르면 다시 켜집니다(Chrome 권한 창에서 "매번 허용"을 고르면 다음부터 묻지 않습니다).
- 이 파일은 Import JSON으로 불러올 수 있고, 모든 프로젝트가 새 프로젝트로 추가됩니다.
- Safari에는 이 기능이 없습니다. More → **Export all projects (JSON)**으로 가끔 내보내세요.

## 공유 링크 (읽기 전용)

More → Share → **Copy view-only link**를 누르면 지금 프로젝트가 담긴 주소가 복사됩니다. 받은 사람이 열면 읽기 전용으로 보이고, **Save to my projects**로 자기 프로젝트에 저장할 수 있습니다.

- 일정은 주소의 `#` 뒤에 압축되어 들어 있어서 서버로 전송되지 않습니다. 대신 링크를 가진 사람은 누구나 볼 수 있습니다(메모 포함).
- 링크는 복사한 순간의 내용입니다. 이후에 고친 것은 반영되지 않으니 다시 보내세요.
- 태스크가 아주 많아 링크가 길면 일부 채팅 앱이 자를 수 있습니다. 그때는 JSON 파일을 보내세요.

## CSV (엑셀·구글 시트)

More → Spreadsheet에서 지금 프로젝트를 CSV로 내보내거나, CSV를 새 프로젝트로 불러옵니다.

- 열: `id,name,type,group,start,end,progress,dependencies,color,notes,baseline_start,baseline_end` (`group`은 속한 그룹의 id)
- 엑셀에서 한글이 깨지지 않게 UTF-8 BOM을 붙입니다. `=`·`+`·`-`·`@`로 시작하는 이름은 엑셀이 수식으로 실행하지 않게 앞에 `'`를 붙여 내보내고, 불러올 때 뗍니다.
- 불러올 때는 `name`과 `start` 열만 있으면 됩니다. id가 비어 있으면 새로 매기고, 날짜는 `2026-12-01`·`2026/12/1`·`2026.12.1`, 진행률은 `40`·`40%`를 받습니다(미국식 `12/01/2026`은 받지 않음). 쉼표·세미콜론·탭 구분 모두 됩니다.

## PNG 내보내기

"Export PNG"는 화면을 캡처하지 않고 태스크 데이터로 이미지를 새로 그립니다. 그래서 세로 스크롤 아래 태스크까지 모두 들어가고(접힌 그룹의 자식과 필터에 걸린 행은 화면처럼 빠짐), 가로는 첫 태스크부터 마지막 태스크까지(기준선이 있으면 기준선까지) 담깁니다. 마일스톤·그룹·공휴일·늦은 태스크 표시·기준선도 화면처럼 그립니다. 지금 화면의 줌(일·주·월, 칸 너비)을 그대로 쓰므로 "Fit"을 누른 뒤 내보내면 한눈에 보는 이미지가 됩니다. 기본 2배 해상도이고, 이미지가 너무 크면 해상도를 낮추며, 그래도 크면 Week나 Month로 줄이라고 안내합니다.

## 동료와 공유하기

데이터는 각자의 브라우저에만 저장되므로, 같은 주소(https://ben6306.github.io/my-gantt/)를 열어도 동료에게 내 태스크가 보이지 않습니다. 지금은 파일을 주고받는 방식으로 공유합니다.

1. 내가 **Export JSON**을 누르면 `프로젝트이름-날짜.json` 파일이 생깁니다.
2. 파일을 메신저나 메일로 동료에게 보냅니다.
3. 동료가 같은 주소에서 **Import JSON**으로 그 파일을 고르면 태스크·색상·프로젝트 이름이 **새 프로젝트로** 추가됩니다.
4. 동료가 고친 뒤 다시 **Export JSON**으로 보내 주면 내가 **Import JSON**으로 받습니다.

주의할 점:
- **한 번에 한 사람만 고치세요.** 불러오기는 두 사람의 변경을 합치지 않고 받은 파일을 새 프로젝트로 추가할 뿐이라, 동시에 고치면 어느 쪽 변경을 살릴지 직접 골라야 합니다. "지금 누가 고치는 중"인지 정해 두는 것이 좋습니다. 받은 뒤 예전 프로젝트가 필요 없으면 ▾ 메뉴에서 지우면 됩니다.
- 불러오기를 잘못했으면 바로 ⌘Z(Ctrl+Z)로 되돌릴 수 있습니다. 새로고침한 뒤에는 되돌릴 수 없습니다.
- 보기만 하면 되는 사람에게는 **Export PNG** 이미지나 **공유 링크**(More → Share)를 보내면 됩니다.

여러 사람이 실시간으로 함께 고쳐야 한다면 온라인 데이터베이스(Supabase 등)로 저장 방식을 바꾸는 작업이 필요합니다.

## 백업과 복원

데이터는 쓰는 브라우저 안에만 저장됩니다. 브라우저 데이터를 지우거나 다른 브라우저·컴퓨터로 옮기면 보이지 않으니 가끔 내보내기 해 두세요.

- **Export JSON**: `프로젝트이름-날짜.json` 파일이 다운로드 폴더에 저장됩니다. 프로젝트 이름도 함께 들어갑니다.
- **Import JSON**: 백업 파일을 고르면 **새 프로젝트로 추가**하고 그 프로젝트로 전환합니다. 지금 프로젝트는 그대로 남습니다. 모든 프로젝트 백업(자동 저장 파일, Export all projects)을 고르면 모든 프로젝트가 새 프로젝트로 추가됩니다.
- **Export all projects (JSON)** (More → Backup): 모든 프로젝트를 한 파일로.
- 날짜·진행률·id가 잘못된 파일은 불러오지 않고 이유를 알려 줍니다. 없는 태스크를 가리키는 선행 연결은 빼고 불러옵니다.
- 백업 형식 대신 태스크 배열만 있는 JSON도 불러올 수 있습니다.

```json
{ "app": "my-gantt", "version": 1, "exportedAt": "2026-11-28T00:00:00.000Z", "projectName": "Website launch", "tasks": [ ... ] }
```

모든 프로젝트 백업은 version 2입니다.

```json
{ "app": "my-gantt", "version": 2, "exportedAt": "2026-11-28T00:00:00.000Z", "projects": [{ "name": "Website launch", "tasks": [ ... ] }] }
```

## 배포

`master` 브랜치에 푸시하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트와 빌드를 거쳐 GitHub Pages에 자동으로 배포합니다. 진행 상황은 저장소의 Actions 탭에서 볼 수 있습니다.

배포된 사이트와 `localhost`는 브라우저 저장 공간이 따로라서 데이터가 공유되지 않습니다. 옮기려면 한쪽에서 내보내기 한 파일을 다른 쪽에서 불러오세요.

## 공휴일 목록 갱신

한국 공휴일은 `src/holidays.js`에 직접 적혀 있습니다(2025~2027년). 음력 명절·대체공휴일·선거일이 해마다 달라서, 새해가 오기 전에 우주항공청 월력요항을 보고 다음 해를 추가하세요. 날짜 순서대로 적어야 테스트가 통과합니다.
